Detailed Description

Declared BIRENSUPA APIs of Single-Precision Floating-Point Mathematical Functions.

Version
1.0.0
Date
2024-1-30

The section describes standard functions of single float precision. To use these functions you do not need to include any additional header files in your program. All functions defined in this section are accessible within device code, including both kernel and device functions. Notably, some of these functions also have accessibility from host code.
